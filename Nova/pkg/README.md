# PKG notes

`../build-pkg.sh` (or the GitHub workflow) produces `build/IV0000-PSMK00001_00-PS4MARKET0000001.pkg`.

- Title ID `PSMK00001`, content ID `IV0000-PSMK00001_00-PS4MARKET0000001` (both set in `Makefile.ps4`; the content ID must be 36 chars).
- `sce_sys/param.sfo` is generated by the Makefile with the toolchain's `PkgTool.Core sfo_*` commands.
- `sce_sys/icon0.png` (this folder) is an original 512x512 icon.
- This is an OpenOrbis "fake" PKG: it is for consoles already set up to run homebrew, and compatibility with a given firmware depends on that environment, not on this PKG. Firmware 14.02 support is not established.
- The catalog is read from `/data/ps4market/catalog.json` at runtime, so listings can change without rebuilding.
- Only package and distribute software you are authorized to use.
